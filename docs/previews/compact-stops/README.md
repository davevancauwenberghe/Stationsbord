# Compact stop list

Fixture data, not a live service guarantee.

- `mobile.png`: Dutch, light theme, 390px train details.
- `desktop.png`: Dutch, dark theme, 1280px train details.

Ordinary stops show one time with a small event/status label. Partial
cancellations retain a secondary line for the other event. Delayed times retain
the scheduled time in the tooltip and screen-reader text.
